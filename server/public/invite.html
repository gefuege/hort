<>Hort

You're invited to Hort.

Three steps to your own vault. Your keys stay on your devices.

1. Install Hort

# Homebrew
$ brew install sebastian-breitzke/tap/hort
# Scoop
> scoop bucket add sebastian-breitzke https://github.com/sebastian-breitzke/scoop-bucket
> scoop install hort
# npm, or a .deb, .rpm or plain binary from github.com/gefuege/hort/releases
$ npm install -g @s16e/hort
# any OS with Node.js
$ npm install -g @s16e/hort

2. Create your vault


  
Choose a passphrase. Keep the Emergency Kit it prints somewhere safe, apart from the passphrase. The invitation works once.





3. Add a passkey


Open hort.pm/vault, unlock with your Emergency Kit and register a passkey. From then on the passkey signs you in, in the browser and when your agent asks you for a secret.
