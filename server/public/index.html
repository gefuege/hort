// install

Install it, run hort init.

# Homebrew
$ brew install sebastian-breitzke/tap/hort
# Scoop
> scoop bucket add sebastian-breitzke https://github.com/sebastian-breitzke/scoop-bucket
> scoop install hort
# npm, or a .deb, .rpm or plain binary from github.com/gefuege/hort/releases
$ npm install -g @s16e/hort
# any OS with Node.js
$ npm install -g @s16e/hort
# let your agents ask for secrets
$ claude mcp add hort -- hort mcp
$ codex mcp add hort -- hort mcp

Binaries, .deb and .rpm packages: GitHub Releases. Later, hort update keeps it current.

You have an invitation

  • Open your invite link. It shows your command: hort init --invite <code>
  • Run it and set a passphrase. Your vault syncs through hort.pm, and the web app opens with a passkey.

No invitation

  • Local only: hort init works without an account.
  • Host Hort yourself for sync and the web app: self-hosting guide. Or tell your agent: “Set up Hort for me with hort.pm/self-host.md.”
  • Or ask for an invitation on GitHub.
