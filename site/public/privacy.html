Privacy

This website is static. It sets no tracking cookies, runs no scripts, uses no analytics and loads no third-party resources: fonts and images are served from hort.pm itself.

Hosting

hort.pm is served by Cloudflare. As with any web server, Cloudflare processes technical request data (for example IP address, time and requested page) to deliver the site and keep it secure.

The Hort CLI

The CLI works offline and sends no data to any server.
